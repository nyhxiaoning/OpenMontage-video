# React PC Admin Template

基于 React 18 + TypeScript + Ant Design + TailwindCSS 的现代化 PC 端管理系统模板。
## 核心问题：threejs渲染框架，最常见问题：版本不一致。
### npm list three @react-three/fiber @react-three/drei
three@0.160
fiber@8.x
drei@9.x

### 标准版本的组合
```
npm install three@0.158 @react-three/fiber@8.15 @react-three/drei@9.88


```

## 🚀 技术栈

- **框架**: React 18 + TypeScript
- **构建工具**: Vite 5
- **UI 组件库**: Ant Design 5
- **CSS 框架**: TailwindCSS
- **状态管理**: Redux Toolkit + Zustand
- **路由**: React Router 6
- **网络请求**: Axios + React Query
- **代码规范**: ESLint + Prettier + Husky
- **包管理**: pnpm

## 📦 安装依赖

```bash
pnpm install
```

## 🛠️ 开发

```bash
pnpm dev
```

## 🏗️ 构建

```bash
pnpm build
```
